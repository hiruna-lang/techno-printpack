# Techno Industries website

Eight frontend-only packaging-company pages built in this workspace, with a separate existing Green Techno Farm site under `farm/`. HTML, CSS and vanilla JavaScript deploy directly to standard static hosting. No backend, database or form storage is required.

## Current content source

The user-supplied **Technopack 2.pdf** is the primary source for packaging-company facts. All 13 pages were reviewed. See `COMPANY-CONTENT-AUDIT.md` for the page-by-page reconciliation and editorial limits.

`assets/data/company-profile.json` contains the normalized facts: Techno Industries identity, company vision, three group companies, eight industries, ten products, six flute options, five board options, ten carton structures, PVC formats, printing methods, finishes and contact details.

`tools/company_profile_content.py` applies this content last in the shared builder. It supersedes earlier web-derived draft copy while retaining the reference designs. Edit the JSON and this module for future factual updates. The original PDF at `E:/Technopack 2.pdf` and the original photos under `images/` were not modified.

## Pages and preview

- `index.html`: Home, with automatic manufacturing-photo crossfades.
- `about.html`: Company overview, actual vision, focus, commitments and group details.
- `products.html`: Ten product lines, category filters, carton structures and PVC formats.
- `capabilities.html`: Printing, die-cutting, structures, finishing, flutes and board options.
- `industries.html`: The eight sectors listed in the profile.
- `quality.html`: Source-backed certification/material statements and documentation requests.
- `quotation.html`: Frontend enquiry builder with product, flute, board and finish choices.
- `contact.html`: Published address, phone/mobile and all three email addresses; enquiry draft builder.

Gallery has been removed from public pages, header, footer and sitemap. The original photos remain available. The existing Farm site and its navigation link are preserved.

Preview with VS Code Live Server, open `index.html` directly, or run:

```powershell
python -m http.server 5173 --bind 127.0.0.1
```

Visit http://127.0.0.1:5173/. Internet access loads Google Fonts, pinned GSAP/ScrollTrigger, Swiper, Lucide and the map embed. Content has font fallbacks and remains readable without those libraries.

## Authoring structure

- `assets/css/`: shared design system, responsive rules, page reference styles, navigation and `company-profile.css`.
- `assets/js/`: shared navigation/autoplay/filters, animation, quotation and contact behavior.
- `assets/media/`: optimized photos, vector structure illustrations and PDF-derived assets in `profile/`.
- `assets/data/company-profile.json`: source facts and product categories.
- `tools/build_site.py`: shared static-page builder; Python is an optional authoring tool, not a hosting dependency.
- `tools/*_reference.py`: page compositions based on the user's visual references.
- `tools/navigation.py`: About/Industries dropdowns, rendered by the shared header.
- `tools/company_profile_content.py`: final source-aligned content and quotation choices.

Run `python tools/build_site.py` after authoring. It overwrites the eight main HTML files, sitemap, robots file and selected generated assets. Keep persistent edits in the appropriate source module. Do not run the earlier migration/enable scripts for routine edits. Farm authoring uses its own existing scripts and is not regenerated by the packaging builder.

## Navigation and images

About Us and the existing Industries item have dropdowns. Other header items are direct links. Desktop supports hover, click, Tab, arrows, Home/End and Escape; mobile uses expandable sections. About links open their relevant details. The Farm company link opens `farm/index.html`; Grand Techno remains the existing unconfigured company button.

The packaging-site logo is the actual Techno Industries wordmark extracted from the PDF, stored at `assets/media/profile/company-logo.png`. The footer places it on white for contrast. The older generated logo files remain in the repository but are not used by the main header/footer.

Original company images under `images/` remain untouched. Existing 640px/1600px WebP derivatives support responsive images. All 28 supplied packaging CR3 photos were properly developed through rawpy/LibRaw before web encoding. `assets/media/inventory.json` records the original asset inventory.

`assets/media/profile/` contains examples extracted from the company profile, labelled as examples rather than specific stock packshots. Original vector diagrams are labelled as illustrations. Replace them with approved product packshots when available, updating alt text, dimensions and captions.

The homepage photos rotate every five seconds with a one-second crossfade and a small pause/play control. Autoplay stops for reduced-motion preferences and hidden tabs; the first image remains visible without JavaScript.

## Enquiries and WhatsApp

Forms validate fields and prepare messages in memory. Nothing is sent or stored until the visitor sends it in their email or messaging app. Contact provides an email draft and copy action. Quotation includes product type, quantity, dimensions, flute, board, finish and print requirements. Product cards preselect a supported quotation type.

The PDF publishes a mobile telephone number but does not confirm WhatsApp service. `assets/js/config.js` therefore keeps `whatsappNumber` empty. After confirmation, enter the official number as international digits only, without plus signs, spaces or a local leading zero. WhatsApp controls then open an encoded message for the visitor to review and send. Do not claim successful submission merely because another app opens.

The published email contacts are `sampath@technoind.biz`, `gayani@technoind.biz` and `info@technoind.biz`. The main enquiry inbox remains `info@technoind.biz`. Business hours and official social profiles are not supplied in the PDF. The map uses the company name/address search; confirm the exact pin directly before replacing it with a verified embed.

## Deploy

Upload the eight main HTML files, `assets/`, `sitemap.xml` and `robots.txt` to the document root. Include `farm/` and its referenced assets if deploying the existing Farm site too. Do not upload `.git`, `tmp/`, original RAW photos or development `tools/`. Keep file casing unchanged.

Canonicals, Open Graph metadata, sitemap and organization data use `https://www.technoprintpack.com/`. Update all of them if the final deployed domain changes. Enable HTTPS, compression and suitable static caching through the host. Set permanent redirects from legacy PHP URLs to the relevant HTML pages. No public hosting configuration was changed by this local update.
